# ADR 0005 — Repositório de destino JOGA

- **Status:** Aprovado pelo usuário.
- **Data:** 2026-11-01
- **Decisores:** responsável pelo produto (aprovação nesta conversa).

## Decisão

O repositório exclusivo do projeto JOGA é `https://github.com/kramirodev/Joga`. Uma decisão provisória anterior de destino fica substituída. O projeto permanece independente, desenvolvido do zero, sem dependência operacional do repositório anterior.

## Evidências

- O workspace local informa `origin` como `https://github.com/kramirodev/Joga`.
- A consulta somente de leitura à API do GitHub confirmou `name: Joga`, `full_name: kramirodev/Joga`, branch padrão `main` e repositório disponível.
- Como o nome remoto já corresponde à decisão, nenhuma renomeação ou escrita remota foi necessária.
