# ADR 0004 — Nome do produto: JOGA

- **Status:** Substituído quanto ao repositório por `ADR 0005`; decisão de nome JOGA permanece válida.
- **Data:** 2026-11-01
- **Decisores:** responsável pelo produto (aprovação nesta conversa).

## Decisão

O nome vigente do projeto e produto é **JOGA**. Não usar o nome anterior do produto. O destino do repositório é registrado na decisão vigente de repositório.

## Consequências

- Atualizar referências ativas de branding nos documentos de governança, objetivos, prompts e documentação técnica para JOGA.
- Manter ADRs anteriores como registro histórico, marcados como supersedidos nos pontos em conflito.
- Nenhuma ação no GitHub ou alteração de remoto é autorizada por esta decisão.
