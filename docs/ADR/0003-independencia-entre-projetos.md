# ADR 0003 — Independência entre projetos

- **Status:** Substituído quanto a branding e repositório pelas ADRs 0004 e 0005; a independência permanece válida.
- **Data:** 2026-11-01
- **Decisores:** responsável pelo produto (aprovação nesta conversa).

## Decisão vigente

O JOGA é desenvolvido do zero como projeto independente. O projeto anterior está em repositório separado e não há obrigação de auditá-lo, preservá-lo operacionalmente, migrá-lo, importá-lo ou reutilizar código, arquitetura, banco ou histórico. Uma consulta futura é opcional e somente conceitual.

## Consequências

- Não existe dependência operacional entre os projetos.
- A Fase 0 e as fases seguintes não exigem ações relativas ao projeto anterior.
- O nome e o repositório vigentes são definidos pelas ADRs posteriores.
