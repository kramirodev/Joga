# ADR 0002 — Nome do produto e repositório vinculado

- **Status:** Substituído por ADR 0004 quanto ao nome e ADR 0005 quanto ao repositório e à independência entre projetos.
- **Data:** 2026-11-01
- **Decisores:** responsável pelo produto (aprovação nesta conversa).

## Registro histórico

Esta ADR documenta uma decisão intermediária de nome e destino remoto que foi posteriormente revista. Ela não é fonte operacional para o produto atual.

## Consequências atuais

Consultar ADRs 0004 e 0005 para o nome vigente, o repositório de destino e a ausência de dependência operacional do projeto independente. Não executar ações remotas com base nesta decisão histórica.
